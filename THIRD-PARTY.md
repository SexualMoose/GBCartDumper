## Re-implemented protocol (no source copied into this repo)

The Kotlin (`app/src/main/kotlin/com/tyler/gbcartdumper/flasher/`) and Python (`tools/`) code
re-implement the jrodrigo GB Cart Flasher rev.c serial protocol. Code comments say the constant
values follow the original firmware / gbcflsh `const.h`. No files from these projects are
included here, and their licenses are unverified.

- jrodrigo GB Cart Flasher rev.c — original hardware + firmware
- [Nold360/gbcflsh](https://github.com/Nold360/gbcflsh) — Qt host application
- [Tauwasser/GBCartFlasher](https://github.com/Tauwasser/GBCartFlasher) — firmware rewrite
- Pan Docs cartridge-header reference (cited in `CartHeader.kt`)
